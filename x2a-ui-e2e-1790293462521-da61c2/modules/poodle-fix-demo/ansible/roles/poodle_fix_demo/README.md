# poodle_fix_demo

This Ansible role fixes the POODLE SSL vulnerability in Apache web servers by updating SSL protocol configuration.

## Description

The POODLE (Padding Oracle On Downgraded Legacy Encryption) vulnerability affects SSL 3.0 and older TLS protocols. This role:

- Updates Apache SSL configuration to disable vulnerable protocols
- Enables only TLSv1.2 protocol by default
- Restarts Apache and SSH services after configuration changes
- Provides configurable SSL protocol settings

## Requirements

- Apache2 web server installed and configured
- SSL module enabled in Apache
- Root or sudo access for configuration changes

## Role Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `apache_ssl_config_path` | `/etc/apache2/mods-available/ssl.conf` | Path to Apache SSL configuration file |
| `ssl_protocols` | `"-all +TLSv1.2"` | SSL protocols to enable/disable |
| `restart_services` | `true` | Whether to restart services after changes |

## Dependencies

None.

## Example Playbook

```yaml
- hosts: webservers
  become: true
  roles:
    - poodle_fix_demo
```

With custom variables:

```yaml
- hosts: webservers
  become: true
  roles:
    - role: poodle_fix_demo
      vars:
        ssl_protocols: "-all +TLSv1.2 +TLSv1.3"
        apache_ssl_config_path: /etc/apache2/conf-available/ssl-params.conf
```

## Security Notes

- This role addresses CVE-2014-3566 (POODLE vulnerability)
- Default configuration enables only TLSv1.2 for maximum compatibility
- Consider enabling TLSv1.3 for enhanced security on supported systems
- Test SSL configuration after applying changes

## Verification

After running this role, verify the fix:

```bash
# Check Apache configuration
sudo apache2ctl configtest

# Test SSL protocols
nmap --script ssl-enum-ciphers -p 443 your-server

# Verify POODLE vulnerability is fixed
nmap --script ssl-poodle -p 443 your-server
```
