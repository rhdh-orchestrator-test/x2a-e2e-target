# Migration Plan: fastapi-tutorial

**TLDR**: This cookbook deploys the FastAPI application from `https://github.com/dibanez/fastapi_tutorial.git` at revision `main` into `/opt/fastapi-tutorial`, creates a Python virtual environment, installs the repository requirements, installs and configures PostgreSQL, creates the `fastapi` database user and `fastapi_db` database, writes an application `.env` file, and manages the `fastapi-tutorial` systemd service listening on `0.0.0.0:8000`. The migration should preserve the configured paths, service behavior, database settings, and platform-specific package branches while moving the hardcoded database password to the Ansible Vault or AAP secret variable `fastapi_db_password`.

  - Application entry point: `app.main:app`
  - Bind address: `0.0.0.0`

## Module Explanation

The cookbook performs operations in this order:

1. **Platform-specific system package installation** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - On Fedora/RHEL platforms, installs `python3`, `python3-pip`, `git`, `postgresql-server`, `postgresql-contrib`, and `libpq-devel`.
   - On non-Fedora/RHEL platforms, installs `python3`, `python3-pip`, `python3-venv`, `git`, `postgresql`, `postgresql-contrib`, and `libpq-dev`.
   - On Fedora/RHEL platforms, runs `postgresql-setup --initdb` only when `/var/lib/pgsql/data/PG_VERSION` does not exist.
   - Ansible resources: `ansible.builtin.package` and guarded `ansible.builtin.command`.
   - No package versions are pinned.

2. **Create the application directory** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Creates `/opt/fastapi-tutorial` recursively.
   - Sets owner and group to `root:root`.
   - Sets mode to `0755`.
   - Chef resource: `directory[node['fastapi_tutorial']['app_path']]`.

3. **Synchronize the Git repository** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Checks out `https://github.com/dibanez/fastapi_tutorial.git`.
   - Synchronizes revision `main` into `/opt/fastapi-tutorial`.
   - Uses an Ansible `ansible.builtin.git` task with `dest: /opt/fastapi-tutorial`, `repo: https://github.com/dibanez/fastapi_tutorial.git`, and `version: main`.
   - Chef resource: `git[node['fastapi_tutorial']['app_path']]`.

4. **Create the Python virtual environment** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Runs `python3 -m venv /opt/fastapi-tutorial/venv`.
   - Runs only when `/opt/fastapi-tutorial/venv` does not exist.
   - Chef resource: `execute[create_venv]`.

5. **Install Python dependencies** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Runs `/opt/fastapi-tutorial/venv/bin/pip install -r /opt/fastapi-tutorial/requirements.txt`.
   - Uses `/opt/fastapi-tutorial` as the working directory.
   - Preserves the explicit Chef `run` behavior.
   - May be implemented with `ansible.builtin.pip` using the requirements file and virtual environment.
   - Chef resource: `execute[install_dependencies]`.

6. **Enable and start PostgreSQL** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Enables the `postgresql` service at boot.
   - Starts the `postgresql` service immediately.
   - Ansible resource: `ansible.builtin.service`.
   - Chef resource: `service[postgresql]`.

7. **Create the PostgreSQL user and database** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Creates PostgreSQL user `fastapi`.
   - Assigns the password from the migrated secret variable `fastapi_db_password`.
   - Creates database `fastapi_db`.
   - Sets `fastapi` as the database owner.
   - Grants all privileges on `fastapi_db` to `fastapi`.
   - Uses `community.postgresql.postgresql_user`, `community.postgresql.postgresql_db`, and `community.postgresql.postgresql_privs` where possible.
   - Executes database tasks as the PostgreSQL administrative user.
   - Replaces the original shell commands that ignore failures with idempotent PostgreSQL modules.
   - Chef resource: `execute[create_db_user]`.

8. **Create the application environment file** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Creates `/opt/fastapi-tutorial/.env`.
   - Writes:
     ```dotenv
     PROJECT_NAME="FastAPI Tutorial"
     API_VERSION=1.0.0
     DATABASE_URL=postgresql://fastapi:{{ fastapi_db_password }}@localhost/fastapi_db
     ```
   - Sets owner and group to `root:root`.
   - Sets mode to `0644` to preserve the Chef behavior, although a more restrictive mode is recommended because the file contains a password.
   - Consumes the vaulted or AAP-managed variable `fastapi_db_password`.
   - Chef resource: `file[#{node['fastapi_tutorial']['app_path']}/.env]`.

9. **Create the systemd service unit** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
   - Creates `/etc/systemd/system/fastapi-tutorial.service`.
   - Installs the following unit:
     ```ini
     [Unit]
     Description=FastAPI Tutorial Service
     After=network.target postgresql.service

     [Service]
     Type=simple
     User=root
     WorkingDirectory=/opt/fastapi-tutorial
     Environment="PATH=/opt/fastapi-tutorial/venv/bin"
     ExecStart=/opt/fastapi-tutorial/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
     Restart=always

     [Install]
     WantedBy=multi-user.target
     ```
   - Preserves the `root` runtime user, application path, Uvicorn entry point, bind address, port, restart policy, and PostgreSQL startup ordering.
   - Sets owner and group to `root:root`.
   - Sets mode to `0644`.
   - Uses an Ansible `ansible.builtin.copy` or `ansible.builtin.template` task.
   - Notifies the systemd reload handler when the unit changes.
   - Chef resource: `file[/etc/systemd/system/#{service_name}.service]`.

10. **Reload systemd** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
    - Defines `systemctl daemon-reload`.
    - Runs only when `/etc/systemd/system/fastapi-tutorial.service` changes.
    - Maps to an Ansible handler using `ansible.builtin.systemd` with `daemon_reload: true`.
    - Chef resource: `execute[systemd_reload]`.

11. **Enable and start the FastAPI service** (`cookbooks/fastapi-tutorial/recipes/default.rb`):
    - Enables the `fastapi-tutorial` service at boot.
    - Starts the `fastapi-tutorial` service immediately.
    - Starts the service after the unit is deployed and systemd has reloaded its unit definitions.
    - Ansible resource: `ansible.builtin.systemd`.
    - Chef resource: `service[fastapi-tutorial]`.
