# Migration Plan: setup-automate

**TLDR**: This is a simple Chef deployment module consisting of two bash scripts that install and configure Chef Automate and Chef Infra Server. The scripts set up a Chef server with a single user and organization.

## Service Type and Instances

**Service Type**: Chef Infrastructure Management (Chef Automate and Chef Infra Server)

**Configured Instances**:
- **Chef Automate + Chef Infra Server**: Deployed via deploy-automate.sh
  - Location/Path: Default installation paths
  - Port/Socket: Default ports (443 for Automate UI)
  - Key Config: Single user and organization configuration

- **Chef Infra Server only**: Deployed via deploy-chef-server.sh
  - Location/Path: Default installation paths
  - Port/Socket: Default ports (443 for Chef Server UI)
  - Key Config: Single user and organization configuration

## File Structure

```
deploy-automate.sh
deploy-chef-server.sh
```

## Module Explanation

The module consists of two bash scripts that perform the following operations:

1. **deploy-automate.sh**:
   - Sets the system hostname to the configured value
   - Configures system parameters for Chef Automate:
     - vm.max_map_count=262144
     - vm.dirty_expire_centisecs=20000
   - Downloads the Chef Automate CLI tool
   - Deploys Chef Automate and Chef Infra Server with default settings
   - Creates a Chef user with the specified credentials
   - Creates a Chef organization and associates the user with it
   - Generates PEM key files for the user and organization

2. **deploy-chef-server.sh**:
   - Sets the system hostname to the configured value
   - Configures system parameters for Chef Server:
     - vm.max_map_count=262144
     - vm.dirty_expire_centisecs=20000
   - Downloads the Chef Automate CLI tool
   - Deploys only Chef Infra Server (without Automate) with default settings
   - Creates a Chef user with the specified credentials
   - Creates a Chef organization and associates the user with it
   - Generates PEM key files for the user and organization

Both scripts use the same set of configurable variables:
- hostname: The hostname for the Chef server
- username: Chef admin username
- longusername: Full name of the admin user
- useremail: Email address for the admin user
- userpassword: Password for the admin user
- orgname: Short name for the Chef organization
- longorgname: Full name of the Chef organization
