# poodle_fix_demo

Fix POODLE SSL vulnerability in Apache web server.

## Description

This role fixes the POODLE SSL vulnerability (CVE-2014-3566) by updating Apache SSL configuration to disable vulnerable protocols and enforce TLS 1.2. The role updates the SSL protocol configuration in the Apache SSL configuration file and restarts the necessary services.

## Requirements

- Apache2 web server installed and configured
- SSL module enabled in Apache
- Root or sudo access for configuration changes

## Role Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `apache_ssl_config_path` | `/etc/apache2/mods-available/ssl.conf` | Path to Apache SSL configuration file |
| `ssl_protocol_config` | `SSLProtocol -all +TLSv1.2` | SSL protocol configuration string to fix POODLE vulnerability |
| `restart_services` | `[apache2, sshd]` | Services to restart after SSL configuration change |

## Dependencies

None.

## Example Playbook

```yaml
- hosts: webservers
  become: true
  roles:
    - poodle_fix_demo
```

## Security Notes

This role specifically addresses the POODLE vulnerability by:
- Disabling all SSL protocols (`-all`)
- Enabling only TLS 1.2 (`+TLSv1.2`)
- Restarting Apache2 and SSH services to apply changes

## Testing

After applying this role, you can verify the SSL configuration:

```bash
# Check Apache SSL configuration
grep SSLProtocol /etc/apache2/mods-available/ssl.conf

# Test SSL configuration
apache2ctl configtest

# Verify TLS 1.2 is working
openssl s_client -connect localhost:443 -tls1_2
```
