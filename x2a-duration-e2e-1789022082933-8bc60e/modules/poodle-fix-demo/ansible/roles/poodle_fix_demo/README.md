# poodle_fix_demo

Fix POODLE SSL vulnerability in Apache web server

## Description

This role fixes the POODLE SSL vulnerability by updating Apache SSL configuration to disable older SSL protocols and enforce TLS 1.2. It replaces any existing `SSLProtocol` directive in the Apache SSL configuration file with a secure configuration that only allows TLS 1.2.

## Requirements

- Apache web server must be installed
- SSL module must be enabled in Apache
- Root or sudo access required for configuration changes

## Role Variables

Available variables are listed below, along with default values (see `defaults/main.yml`):

```yaml
# Path to Apache SSL configuration file
apache_ssl_conf_path: /etc/apache2/mods-available/ssl.conf

# SSL protocol configuration directive
ssl_protocol_setting: "SSLProtocol -all +TLSv1.2"

# Name of the Apache service
apache_service_name: apache2

# Name of the SSH service
ssh_service_name: sshd
```

## Dependencies

None.

```yaml
- hosts: webservers

```

## Security Notes

This role addresses the POODLE (Padding Oracle On Downgraded Legacy Encryption) vulnerability by:

1. Disabling all SSL protocols (`-all`)
2. Enabling only TLS 1.2 (`+TLSv1.2`)
3. Creating a backup of the original configuration file

After applying this role, verify the fix by testing SSL configuration:

```bash
# Test SSL configuration
openssl s_client -connect localhost:443 -tls1_2

# Verify POODLE vulnerability is fixed
nmap --script ssl-poodle localhost -p 443
```
